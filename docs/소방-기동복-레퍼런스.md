# 소방 기동복 레퍼런스 (그림 생성용)

사용자(김태의)가 "소방 기동복"이라고 하면 그림·교안·인포그래픽 속 소방관은 **이 복장**으로 그린다.
생성 방법·고정 프롬프트는 `.claude/skills/gpt-image/SKILL.md` 6장.

## 참고 그림
| 파일 | 보이는 쪽 | 용도 |
|---|---|---|
| `.claude/skills/gpt-image/ref/fire-uniform-front.jpg` | 앞·옆 (가슴 주머니, 태극기 패치, 독수리 자수) | 앞모습·옆모습 장면 `--ref` |
| `.claude/skills/gpt-image/ref/fire-uniform-back.jpg` | 등 (「소방 119」) | 뒷모습 장면 `--ref` |

## 복장 요소
| 부위 | 모양 |
|---|---|
| 바탕색 | 밝은 주황(안전 주황) |
| 남색 부분 | 칼라, 어깨 요크(앞 가슴 윗부분·등 윗부분), 견장, 겨드랑이~밑단 옆판, 소매 끝 |
| 앞판 | 가운데 지퍼, 덮개 달린 가슴 주머니 2개, 왼가슴 금색 독수리 자수, 오른가슴 위 검정 이름표 |
| 왼팔 위 | 태극기 + 「KOREA」 패치 |
| 오른팔 위 | 원형 소방 엠블럼 패치 |
| 등 | 남색 요크 위 흰(반사) 글씨 「소방」(작게) + 큰 「119」, 아래 가로 속도선 3줄 |
| 하의·모자 | 남색 작업 바지 / (선택) 금색 독수리 자수 검정 모자 |

## 주의
- 방화복·근무복·외국 소방복과 섞지 않는다.
- 이름표 실명 금지, 계급장은 요청할 때만.
- 생성 후 「소방 119」·「KOREA」 철자와 태극기 모양을 확인한다.
