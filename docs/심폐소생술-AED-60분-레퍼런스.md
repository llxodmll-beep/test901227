## 2. 원본 PPT에서 바꾼 것

- 범위를 성인 심정지 + AED 로 좁힘 (출혈 · 화상 · 기도폐쇄 · 회복자세 · 영상 슬라이드 제외 — 60분 안에 실습까지).
- 「1분 97% … 5분 25%」 소생률 그래프, 「0~4분 / 4~6분 …」 뇌 손상 표 삭제 — 출처를 확인하지 못함.
- 「수축 : 이완 = 1 : 1」 → 「완전 이완」 (2025 원문 문구 미확인).
- AED 「충전 중에도 가슴압박」 삭제 (일반인 대상 2025 문구 미확인), 「본체와 커넥터 연결」 삭제 (기종마다 다름).
- 인공호흡은 가슴압박 소생술 / 30:2 대상을 나눠 표시, 실습은 가슴압박 소생술.
- 강사 시범 2장(따라 말할 문장 12개), 실습 안내 · 관찰자 확인표 · 실습 2장 · 피드백 장, 처음 질문으로 돌아가는 이해 확인 장 신설.

## 3. 확인 필요

- 모든 발표자 노트의 원문 쪽 번호
- 일반인 알고리즘 그림의 「10초 이내」 표기
- 압박 깊이 상한(6cm) 2025 유지 여부 — 교안에 넣지 않음
- 인공호흡 「1초에 걸쳐」 문구 — 화면에 넣지 않음
- 패드 위치 문구, 물기 · 약물 패치 처리 문구
- 5장 · 27장 도식의 Part 10 그림 번호 · 쪽, 생존사슬 그림의 원 출처
- 「2026 인천119대상 특별승진」 표기, 응급의료법 제5조의2 최신 조문

- 클릭 단계로 하나씩 공개, 숫자는 크게(2.4배 · 73% vs 30% · 약 5cm · 100~120회).
